# ห้องสัมภาษณ์

เกมจำลองการสัมภาษณ์เข้ามหาวิทยาลัยภาษาไทย มีคำถาม 20 ข้อ คำถามต่อยอดแบบเข้มข้น คำแนะนำระหว่างเล่น และสรุปผลการฝึกซ้อม ออกแบบให้เล่นได้ทั้งคอมพิวเตอร์และมือถือ รวมถึง Safari บน iPhone

## เล่นในเครื่อง

เปิด `index.html` ในเว็บเบราว์เซอร์ เลือกคำตอบแล้วลองคิดหรือตอบคำถามต่อยอด ก่อนกดไปข้อต่อไป เกมไม่ต้องติดตั้งแพ็กเกจและเล่นได้โดยไม่เชื่อมต่ออินเทอร์เน็ต

## เผยแพร่ให้เล่นผ่านมือถือ

โปรเจกต์ตั้งค่า GitHub Pages deployment ไว้แล้ว repository เป็นสาธารณะ แต่ Pages ยังไม่ได้เปิดใช้งาน เมื่อ push การเปลี่ยนแปลงไปยัง `main` และเลือก **Settings > Pages > Build and deployment > GitHub Actions** ใน GitHub repository แล้ว workflow จะเผยแพร่เว็บให้อัตโนมัติที่:

`https://sirasitpethethnongchum-blip.github.io/auto/`

หลัง workflow ทำงานสำเร็จ เปิดลิงก์นี้ใน Safari บน iPhone เพื่อเล่นได้เลย
